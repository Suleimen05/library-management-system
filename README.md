# Library Management System

Final Java Spring project by Yeldossuly Suleimen.

## Project Idea

The application is a backend system for managing a library. It will include books, authors, categories, users, borrowing records, reservations, file upload/download, authentication, authorization, and role-based access.

## Main Stack

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- PostgreSQL
- JWT
- Bean Validation
- Swagger UI
- Docker

## Planned Domain Entities

- User
- Role
- Book
- Author
- Category
- Borrowing
- Reservation
- FileResource

## Planned Roles

- ADMIN
- LIBRARIAN
- READER
